# Recon: flowmusic.app landing page → Gemi

Scope: the public landing page only, read in a browser on 2026-11-14. No login, no source code, no network calls inspected. Only layout and interaction patterns were taken; the name, logo, copy, images and music are theirs and are not used.

## Patterns observed

| Pattern on the reference | How Gemi uses it |
|---|---|
| Dark, near-black page with a soft colored glow behind the hero | Same idea, in Gemi's fuchsia/indigo |
| Slim top bar: logo left, two pill buttons right | Gemi logo; Studio and Community |
| Very large centered headline with a one-line subtitle | "Welcome to the fitting room" |
| One big rounded prompt box; icon buttons bottom-left (attach, options, voice), round send button bottom-right | Attach outfit photo, your photo, microphone, send |
| Row of pill chips under the prompt that preset a mode | Steal This Look, Personal Shopper, Just one piece, Closet Search |
| "Get started" row of cards with a caption at the bottom | Four cards, one per thing Gemi can do; gradients instead of photos |
| Feature sections with a small uppercase label above a large heading | Create / Shop / Share |
| Shared-content rows with like and share actions | Trending community looks with like and "Try on me" |

## Not copied

- Their brand, text, imagery, audio and video.
- Their product features (music generation, video, spaces). Gemi keeps only its own functions.
- Accounts and sign-up; Gemi has none.
